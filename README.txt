Калькулятор Windows Forms (.NET 8)

Запуск:
1. Распакуй архив.
2. Открой CalculatorForm/CalculatorForm.csproj в Visual Studio.
3. Нажми F5. Нужны .NET 8 SDK и компонент Visual Studio для разработки
   классических приложений .NET.

Что изменено:
- Form1.cs: ввод чисел, выбор операции, результат, сброс и сообщения об ошибках.
- CalculatorService.cs: сложение, вычитание, умножение и деление.
  Исправлена опечатка в названии исходного CalculatorSerivce.cs.
- Form1.Designer.cs: подключены события Click, надпись 10 заменена на 0.
- Расположение и размеры элементов сохранены.

Как работает:
- Цифры вводят целое число (до 15 цифр). Деление может дать дробный результат.
- Действия выполняются по порядку: 2 + 3 * 4 = дает 20.
- Повторное нажатие операции до ввода второго числа заменяет операцию.
- Повторное нажатие = не повторяет вычисление.
- Del полностью очищает вычисление, а не удаляет одну цифру.
- После результата цифра начинает новое число, операция продолжает расчет.
- При делении на ноль выводится сообщение; цифра или Del начинает заново.
- Ввод с клавиатуры, скобки и кнопка десятичного разделителя не добавлялись.

Примеры для проверки в Visual Studio:
12 + 3 =             -> 15

6 * 7 =              -> 42
7 / 2 =              -> 3,5 (или 3.5, зависит от настроек Windows)
2 + 3 * 4 =          -> 20
8 + * 2 =            -> 16
8 / 0 =              -> Нельзя делить на 0
Затем 3 + 2 =        -> 5
12 + 3 = * 2 =       -> 30
12 + 3 = затем 7     -> 7
12 + Del затем 4 =   -> 4
